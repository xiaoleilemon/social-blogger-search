# 作者搜索获取 · Social Blogger Search

从 SocialDataBridge 的“作者搜索获取”拆分的独立飞书多维表格扩展。输入作者关键词，批量搜索社交平台作者，并把结果写入多维表格。

## 功能

- 支持小红书、抖音、TikTok、快手、哔哩哔哩、微博、好看视频、今日头条、视频号、知乎、Instagram、X，具体可用能力由现有后端提供。
- 批量关键词支持换行或中英文逗号分隔，去重后最多 100 个；获取全部结果或前 1～100 页。
- 抖音支持粉丝量、用户类型筛选。
- 新建结果表，或向现有表更新／新增、始终新增；作者 ID 为空的结果仍作为新记录写入。
- 自选作者字段、自动匹配同名列、自定义字段映射并保存输出配置。
- 增量写入与进度展示，支持停止任务和重新打开插件后恢复当前多维表格的任务。

“更新／新增”按“平台 + 作者 ID”匹配记录，作者 ID 保留大小写，平台为必需输出字段，支持自定义映射到文本或单选列。旧表中没有平台归属的记录保持原样，新的搜索结果会另行新增，不会仅凭相同作者 ID 覆盖历史记录；“始终新增”仍可自行选择是否输出平台。

## 安装与启动

已在 Node.js 18.17.0 验证通过。Element Plus 固定为 `2.13.7`，与 `social-data-bridge` 保持一致。

```sh
npm ci
npm run dev
```

本地地址通常是 `http://localhost:5173/`，以终端输出为准。源码、依赖、环境配置均在本仓库内，无需原 SocialDataBridge 仓库。

此项目依赖飞书宿主提供的表格 API。普通浏览器可访问静态界面；保存密钥、选择表格、创建任务和写入结果需在多维表格扩展中调试。将本地开发地址配置为扩展的调试地址，参见[多维表格扩展脚本开发指南](https://feishu.feishu.cn/docx/U3wodO5eqome3uxFAC3cl0qanIe)。

## 使用

1. 在多维表格中打开扩展，填写并保存 API Key，可从界面中的链接获取密钥。
2. 选择平台，输入作者关键词和获取范围；使用抖音时可选粉丝量与用户类型。
3. 选择新建表格或现有表格，并设置需要的字段及映射。
4. 点击“立即执行”。运行期间可点击“停止任务”，已获取的数据会继续写入后再结束。

API Key 通过飞书 SDK bridge 存储，运行中禁止修改。密钥失效时暂停本地轮询并保留任务身份，按钮显示“恢复任务”；保存相同或新的 API Key 后尝试恢复已有任务，点击“恢复任务”也会恢复旧任务，避免覆盖原进度。恢复期间使用原任务设置；任务结束后按钮回到“立即执行”。要求重新进入插件的保护不会因保存密钥解除。任务和字段设置也通过 bridge 保存；结果写入当前多维表格。

追加写入会读取目标表现有记录，并在写入前保存当前批次的核对信息；SDK 响应超时后先核对实际落表结果，只补缺失记录，保留历史重复行。字段或核对结果有歧义时暂停并保留原因。历史失败任务若没有写入前核对信息，需先人工核对表格。

## 接口环境

本项目使用已有后端，不附带后端服务。

| 命令／模式 | 接口配置 |
| --- | --- |
| `npm run dev` | `.env.development`；`/social/api` 通过 Vite 代理到测试后端 |
| `npm run dev:prod` | `.env.development-prod`；本地开发时通过 Vite 代理到生产后端 |
| `npm run build:test` | `.env.test`；`https://test-lotto.weiyoubot.cn` |
| `npm run build` / `npm run build:prod` | `.env.production`；`https://api.52choujiang.cn` |

开发代理目标由 `VITE_DEV_PROXY_TARGET` 控制。默认覆盖测试地址；临时改为其他后端时，可建立被 Git 忽略的 `.env.development.local` 并设置该变量，无需修改 `vite.config.js`。跨域直接请求需要对应服务允许浏览器访问。不要在环境文件中写入用户 API Key。

保留原功能的作者任务、游标结果、停止任务和表格输出配置接口，以及 `plugin_type=blogger_search` 和现有版本参数。服务端需要同时支持这些接口。

## 验证

```sh
npm test
```

测试使用模拟的飞书 SDK 边界，验证作者字段转换、现有表更新、新增记录、映射校验、写入失败、任务恢复和鉴权失败处理，不调用真实采集服务或修改用户表格。

真实端到端验收需要在飞书中使用有效 API Key，分别验证新建表格和现有表格、任务停止与恢复。

## 构建与发布

只有准备发布时才生成生产产物：

```sh
npm run build:prod
npm run preview
```

生成目录为 `dist/`，预览端口为 `4173`。提交或部署前，确保 `dist/` 与当前源码对应；仓库已有的模板产物不代表本次提取功能。日常修改与测试不会自动构建。

按飞书扩展发布流程提交产物；原模板提供的[发布表单](https://feishu.feishu.cn/share/base/form/shrcnGFgOOsFGew3SDZHPhzkM0e)可作为发布参考。
